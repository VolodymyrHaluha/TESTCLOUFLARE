Так, тепер робимо так, щоб **`volodya-haluha.site` відкривав Flask-сайт з твого комп’ютера через Cloudflare Tunnel**.

Схема:

```text
volodya-haluha.site
↓
Cloudflare DNS
↓
Cloudflare Tunnel
↓
твоєму ПК
↓
http://127.0.0.1:5000
```

Cloudflare Tunnel саме для цього підходить: `cloudflared` встановлює вихідне з’єднання до Cloudflare, а потім public hostname направляється на локальний сервіс, наприклад `localhost:8080`; вхідні порти відкривати не потрібно. ([Cloudflare Docs][1])

---

## 1. Додай домен у Cloudflare

Зайди в Cloudflare:

```text
https://dash.cloudflare.com
```

Далі:

```text
Websites → Add a domain
```

Введи:

```text
volodya-haluha.site
```

Вибери безкоштовний тариф **Free**.

Cloudflare після додавання домену дасть тобі **2 nameservers**. Вони будуть виглядати приблизно так:

```text
name1.ns.cloudflare.com
name2.ns.cloudflare.com
```

У кожного домену nameservers можуть бути різні, тому скопіюй саме ті, які Cloudflare покаже для `volodya-haluha.site`. Cloudflare офіційно пише, що для full setup потрібно додати домен, перевірити DNS і змінити nameservers у реєстратора. ([Cloudflare Docs][2])

---

## 2. Заміни nameservers у Hostinger

Тепер заходиш у Hostinger:

```text
hPanel → Domains → volodya-haluha.site → DNS / Nameservers
```

Далі натисни:

```text
Change Nameservers
```

Обери варіант типу:

```text
Use custom nameservers
```

або:

```text
Change nameservers
```

І встав 2 nameservers, які дав Cloudflare.

Hostinger у своїй інструкції описує шлях: hPanel → DNS → вибрати домен → DNS / Nameservers → Change Nameservers. ([Hostinger][3])

Після цього в Cloudflare натисни:

```text
Check nameservers
```

Активація може бути не миттєва. Іноді це кілька хвилин, іноді довше. Cloudflare пише, що nameservers треба оновити, щоб активувати домен і використовувати більшість сервісів Cloudflare. ([Cloudflare Docs][4])

---

## 3. Коли домен стане Active — створи Tunnel

У Cloudflare відкрий:

```text
Zero Trust → Networks → Tunnels
```

або в новому інтерфейсі:

```text
Networking → Tunnels
```

Натисни:

```text
Create Tunnel
```

Cloudflare у документації вказує саме шлях **Networking → Tunnels → Create Tunnel** для створення тунелю. ([Cloudflare Docs][5])

Назва тунелю:

```text
frop-local
```

Далі вибери:

```text
Cloudflared
```

Потім:

```text
Windows
```

Cloudflare покаже команду для запуску connector.

---

## 4. Не встановлюй як service, якщо хочеш запуск через server.bat

Cloudflare може показати команду типу:

```bat
cloudflared.exe service install eyJhIjoi...
```

Але якщо ти хочеш, щоб сайт працював **тільки коли відкритий server.bat**, краще не встановлювати як службу Windows.

Тобі потрібен токен, який починається приблизно так:

```text
eyJhIjoi...
```

Його треба запускати так:

```bat
"C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel run --token ТУТ_ТВІЙ_TOKEN
```

---

## 5. Додай Public Hostname

У створеному Tunnel знайди розділ:

```text
Public Hostname
```

або:

```text
Routes → Add route → Published application
```

Додай так:

```text
Subdomain: залишити пустим
Domain: volodya-haluha.site
Type: HTTP
URL: 127.0.0.1:5000
```

Це означає:

```text
volodya-haluha.site → http://127.0.0.1:5000
```

Cloudflare описує Published applications як можливість публікувати локальні застосунки в інтернет через public hostname, наприклад `docs.example.com → https://localhost:8080`. ([Cloudflare Docs][6])

Для тесту я би ще додав окремо:

```text
Subdomain: test
Domain: volodya-haluha.site
Type: HTTP
URL: 127.0.0.1:5000
```

Тоді буде:

```text
test.volodya-haluha.site → http://127.0.0.1:5000
```

## 6. Перевір Flask локально

У тебе Flask має відкриватися тут:

```text
http://127.0.0.1:5000
```

Якщо локально не відкривається — домен теж не відкриється.

## 7. Готовий server.bat

Після того як Cloudflare дасть token, зроби `server.bat` приблизно так:

```bat
@echo off
title FROP Flask + Cloudflare Tunnel

cd /d C:\Users\Frop\Desktop\ТВІЙ_ПРОЄКТ

call venv\Scripts\activate

start /B python app.py

timeout /t 5 > nul

"C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel run --token ТУТ_ТВІЙ_ДОВГИЙ_TOKEN

pause
```

Якщо в тебе немає `venv`, тоді:

```bat
@echo off
title FROP Flask + Cloudflare Tunnel

cd /d C:\Users\Frop\Desktop\ТВІЙ_ПРОЄКТ

start /B python app.py

timeout /t 5 > nul

"C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel run --token ТУТ_ТВІЙ_ДОВГИЙ_TOKEN

pause
```

## Найкоротший порядок дій

```text
1. Cloudflare → Add domain → volodya-haluha.site
2. Скопіювати 2 Cloudflare nameservers
3. Hostinger → Domains → volodya-haluha.site → DNS / Nameservers
4. Замінити nameservers на Cloudflare
5. Дочекатися Active у Cloudflare
6. Cloudflare → Zero Trust / Networking → Tunnels → Create Tunnel
7. Назва: frop-local
8. Public Hostname: volodya-haluha.site → http://127.0.0.1:5000
9. Запустити Flask
10. Запустити cloudflared через token або server.bat
```

Найперше зараз зроби: **додай `volodya-haluha.site` у Cloudflare і заміни nameservers у Hostinger на ті, які дасть Cloudflare**.

На цьому екрані ти намагаєшся додати **Google login**. Тут не можна просто натиснути Save — треба спочатку створити **OAuth Client** у Google Cloud і взяти звідти:

```text
Client ID
Client secret
```

Cloudflare прямо пише, що для Google як identity provider треба створити OAuth client у Google Cloud, а потім вставити в Cloudflare **Client ID** і **Client Secret**. ([Cloudflare Docs][1])

## Найпростіший варіант для тебе

Якщо ти хочеш просто вхід через код на пошту, то **Google зараз не потрібен**.

Тоді натисни:

```text
← Back to add a login method
```

І вибери:

```text
One-time PIN
```

Cloudflare One-time PIN надсилає одноразовий код на дозволену email-адресу; для доступу достатньо додати пошту в Access policy. ([Cloudflare Docs][2])

Тобто для тебе буде:

```text
volodya-haluha.site
↓
Cloudflare Access
↓
вводиш galuga2005@gmail.com
↓
приходить код на пошту
↓
вводиш код
↓
сайт відкривається
```

Це найпростіше й без Google Cloud.

## Якщо хочеш саме кнопку Google

Тоді роби так.

### 1. Відкрий Google Cloud Console

Перейди в:

```text
https://console.cloud.google.com
```

Далі створи новий project, наприклад:

```text
Cloudflare Access Login
```

### 2. Відкрий Credentials

У Google Cloud:

```text
APIs & Services → Credentials
```

Потім:

```text
Configure Consent Screen
```

Для звичайного Gmail вибери:

```text
External
```

Cloudflare у своїй інструкції також вказує для звичайного Google/Gmail вибирати **External**, бо це не Google Workspace. ([Cloudflare Docs][1])

### 3. Створи OAuth client

Після consent screen:

```text
Create OAuth client
```

Application type:

```text
Web application
```

Назва, наприклад:

```text
Cloudflare Access
```

### 4. Додай Authorized JavaScript origins

Треба вказати твій Cloudflare Access team domain:

```text
https://ТВІЙ_TEAM_NAME.cloudflareaccess.com
```

Твій team name можна знайти в Cloudflare:

```text
Zero Trust → Settings → Team name and domain
```

Cloudflare у документації пише, що саме team domain треба додати в **Authorized JavaScript origins**. ([Cloudflare Docs][1])

### 5. Додай Authorized redirect URI

У Google Cloud треба додати:

```text
https://ТВІЙ_TEAM_NAME.cloudflareaccess.com/cdn-cgi/access/callback
```

Наприклад, якщо team name у тебе:

```text
galuga2005
```

тоді буде:

```text
https://galuga2005.cloudflareaccess.com/cdn-cgi/access/callback
```

Cloudflare прямо вказує такий redirect URI для Google integration. ([Cloudflare Docs][1])

### 6. Скопіюй Client ID і Client Secret

Після створення Google покаже:

```text
OAuth Client ID
Client secret
```

Скопіюй їх і встав на сторінці, яку ти зараз відкрив:

```text
Client ID → вставляєш OAuth Client ID
Client secret → вставляєш Client secret
```

**Client secret нікому не показуй і не скидай у чат**, бо це як пароль для OAuth-застосунку.

### 7. Поле Email claim

У полі:

```text
Email claim
```

можна вписати:

```text
email
```

Або залишити пустим, якщо Cloudflare не вимагає. Якщо після збереження будуть проблеми з визначенням пошти — постав `email`.

### 8. Збережи й протестуй

Після Save перейди:

```text
Zero Trust → Integrations → Identity providers
```

Біля Google натисни:

```text
Test
```

Cloudflare радить тестувати IdP через кнопку **Test** після налаштування. ([Cloudflare Docs][3])
